# Phase 5 변경 명세

## 목표

브라우저 UI를 차단하지 않는 제한 조합 탐색과 취소 가능한 경량 고급 분석을 제공한다.

## 구현 범위

- QQQ·QLD·SGOV 비중 10% 단계 66개
- 분기·연간 리밸런싱과 QQQ MDD 규칙 조합
- 최대 264개 후보를 전용 Web Worker에서 계산
- 진행률, 완료 상태, 실행 취소
- Sharpe와 MDD를 함께 반영한 내부 정렬 점수
- 상위 5개 후보의 비중, 리밸런싱, CAGR, MDD 표시
- QQQ·QLD·SGOV별 단순 즉시 충격 시나리오

## 안전장치와 한계

- 탐색 결과는 미래 성과 예측이나 최적 투자안이 아니다.
- 전체 중간 조합은 DB에 저장하지 않는다.
- 브라우저 종료 시 계산은 취소된다.
- 충격 시나리오는 상관관계, 회복 경로, 유동성, 연속 변동을 반영하지 않는다.
- 자동 탐색은 264개로 제한해 무료 클라우드와 기기 자원 사용을 통제한다.

## 검증

- 264개 탐색 완료 및 상위 5개 표시
- 실행 중 취소와 UI 복귀
- 10% 단계 후보 66개의 비중 합계 100 확인
- 기존 자산관리·시장 분석 회귀 테스트
