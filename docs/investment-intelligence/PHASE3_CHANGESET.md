# Phase 3 변경 명세

## 목표

추가 유료 데이터나 합성 지표 없이 현재 확보 가능한 실제 QQQ 조정가격과 포트폴리오 스냅샷을 이용해 태블릿 중심 시장 분석 경량판을 제공한다.

## 구현 범위

- Portfolio TWR, QQQ 조정가격, 평가자산 중 최대 3개 비교
- 3개월, 1년, 전체 기간 선택
- 시작점 100 및 누적 변화율 정규화
- 시장 하락, 자산 집중, 레버리지 노출 기반 0~100 상대 위험점수
- 위험 가중치 즉시 재계산, 브라우저 저장, 기본값 복원
- QQQ 최근 63거래일 흐름 기반 과거 유사 시점 3건
- 유사 시점 이후 3·6·12개월 사후 참고 성과
- 원천 데이터, 기준일, 발표 시차, 결측 처리 및 갱신 지연 경고

## 계산 원칙

- 시장 자료는 기존 `/api/benchmark`의 Yahoo Finance QQQ 일별 조정가격만 사용한다.
- 포트폴리오는 기존 일별 스냅샷과 TWR만 사용한다.
- 비교 지표는 동일 기간의 최초 공통 관측값부터 표시한다.
- 10일을 초과한 결측 구간은 차트 선을 연결하지 않는다.
- 유사도는 각 과거 기준일 이전 63거래일 수익 흐름만 사용한다.
- 이후 3·6·12개월 성과는 유사도 계산에 사용하지 않고 별도 사후 참고값으로 표시한다.
- 위험점수는 하락 확률이나 투자 권고가 아닌 상대 점수다.

## 비변경 범위

- 거래 원장, 포트폴리오 계산, 전략 규칙
- Supabase 테이블·RLS·마이그레이션
- 시장 데이터 저장 또는 신규 외부 API

## 검증

- 768px 태블릿에서 3개 지표 선택 및 차트 갱신
- 기간과 정규화 변경 후 동일 조건 재계산
- 위험 가중치 변경 및 초기화
- 과거 유사 시점 3건과 사후 성과 구분
- 데이터 기준일과 4일 이상 지연 경고
- 기존 자산관리 및 Phase 0~1 회귀 테스트
