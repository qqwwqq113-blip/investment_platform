# Phase 4 변경 명세

## 목표

실제 ETF 조정가격을 이용해 일시금·적립식·혼합형 현금흐름과 자산배분 전략을 동일 조건으로 비교하는 경량 연구실을 제공한다.

## 구현 범위

- QQQ, QLD, SGOV 공통 거래일 가격 로드
- 일시금, 월 적립식, 혼합형 납입
- 사용자 자산 비중과 분기·연간 리밸런싱
- QQQ -20%/-30% 조건 신호를 다음 공통 거래일에 반영
- 거래 비용과 단순 실현이익 세율 가정
- 분기, 연간, QQQ MDD 대응 3개 전략 비교
- 최종자산, 순입금, TWR, XIRR, CAGR, MDD, Sharpe, 비용·세금
- 자산곡선과 단순 즉시 충격 시나리오

## 계산 원칙

- Yahoo Finance 일별 조정가격을 사용하며 배당을 별도로 더하지 않는다.
- 모든 전략은 동일한 공통 가격 기간, 납입, 비용, 세금 가정을 사용한다.
- 외부 납입은 TWR 수익에서 제외하고 XIRR에는 실제 납입 시점을 반영한다.
- 세후 값은 실제 신고세액이 아닌 리밸런싱 실현이익의 단순 세율 가정이다.
- 결과는 계좌·거래·DB에 저장하지 않는다.

## 검증

- 합성 상승 가격에서 최종자산·TWR·XIRR 양수 확인
- 공통 거래일 정렬, MDD, 충격, XIRR 정답 케이스
- 태블릿 다크모드에서 3개 전략 E2E 비교
