# Phase 2 변경 명세

## 목표

통합 상황실에서 포트폴리오, 전략, 시장 상태를 한 흐름으로 확인하고 사용자가 카드 표시 여부와 순서를 조정할 수 있게 한다.

## 구현 범위

- 상황실 카드 편집 모달
- 카드 표시/숨김과 위·아래 순서 조정
- 브라우저 저장 및 새로고침 후 복원
- 기본 카드 구성 복원
- 시장 위험점수, QQQ 3개월 흐름, 데이터 기준일 요약 카드
- 모바일과 태블릿에서 시장 분석 화면으로 이동하는 CTA

## 데이터 보호

- 포트폴리오·전략·거래 계산 로직은 변경하지 않는다.
- 카드 구성은 기존 사용자 데이터와 분리된 브라우저 설정으로 저장한다.
- 데이터베이스 및 API 스키마 변경은 없다.

## 검증

- 카드 숨김 후 즉시 반영
- 새로고침 후 표시 상태 유지
- 기본 구성 복원
- 360px 모바일부터 1440px 데스크톱까지 가로 넘침 없음
