# Phase 1A 변경 명세

## 목표

Phase 0에서 확정한 A+ 목업을 실제 애플리케이션 셸에 적용한다. 기존 자산관리 기능과 금융 계산 로직은 유지하면서 화면 체계, 테마, 반응형 내비게이션을 개선한다.

## 구현 범위

- A+ 디자인 토큰 기반의 색상, 간격, 카드, 타이포그래피 체계
- 밝게, 어둡게, 시스템 설정에 맞추기 테마
- 테마 선택의 브라우저 저장 및 재방문 복원
- 데스크톱 고정 사이드바
- 태블릿 및 모바일 고정 하단 내비게이션
- 거래 등록 바로가기와 기존 거래 폼 연결
- 기존 대시보드, 자산관리, 거래 내역, 설정 화면 유지
- 기존 차트, 전략 상태, 자산 배분, 보유 자산, 최근 거래 정보 유지

## 비변경 범위

- 포트폴리오 계산 및 수익률 산식
- 거래 저장 및 조회 흐름
- Cloudflare Worker 및 API 계약
- 데이터베이스 스키마와 마이그레이션
- Yahoo Finance 연동 의미와 전략 판정 규칙

## 반응형 기준

| 화면 | 내비게이션 | 핵심 배치 |
| --- | --- | --- |
| 901px 이상 | 왼쪽 고정 사이드바 | 넓은 카드와 2~3열 정보 배치 |
| 900px 이하 | 하단 5개 항목 내비게이션 | 단일 콘텐츠 영역, 태블릿 2열 허용 |
| 520px 이하 | 하단 5개 항목 내비게이션 | 카드와 지표를 1열로 재배치 |

## 검증 기준

- 1440×900, 1024×768, 768×1024, 390×844, 360×800 화면에서 가로 넘침이 없어야 한다.
- 밝은 테마와 어두운 테마가 모두 렌더링되어야 한다.
- 선택한 테마가 새로고침 뒤에도 유지되어야 한다.
- 기존 거래 등록, 매수/매도, 자금 출처, 설정 저장, 상세 모달, 행 메뉴 흐름이 동작해야 한다.
- 기존 단위 테스트 23개가 모두 통과해야 한다.
